# 教学信息反馈自动生成工具

基于 Python + Streamlit 开发的教学信息反馈自动整理工具。

用于自动整理每周教学信息反馈表，生成符合学院格式要求的标准反馈文件。


## 功能简介

- 自动识别上传文件中的周次信息
- 自动筛选数学与统计学院教师反馈
- 自动整理并合并同类反馈
- 自动生成标准 Excel 反馈文件
- 自动保持学院统一模板格式


## 使用方法

### 1. 上传文件

点击上传按钮，选择本周教学信息反馈原始 Excel 文件。


### 2. 自动处理

系统将自动完成：

- 教师筛选
- 反馈整理
- 内容合并
- 格式生成


### 3. 下载文件

处理完成后，点击下载按钮，获取生成的教学信息反馈文件。


## 注意事项

- 请上传 Excel（.xlsx）格式文件。
- 请使用原始教学信息反馈表，不要修改表格结构。
- 生成文件名称会自动根据周次设置。


## 技术支持

技术栈：

- Python
- Streamlit
- Pandas
- OpenPyXL
